# 🩺 HealthGuard AI – Smart Health Monitoring & Emergency Alert System

HealthGuard AI is a **Flutter-based smart health monitoring application** designed to help users monitor important health parameters and quickly access emergency assistance when needed.

The application provides a simple dashboard for monitoring **heart rate and body temperature**, viewing health history, and accessing an **SOS emergency feature** with location support.

## 🚀 Live Demo

🔗 [HealthGuard AI – Live Demo](https://69f0bfb0846e11fd861c5bf5--stunning-fairy-e9850d.netlify.app/)

## ✨ Features

* ❤️ **Heart Rate Monitoring** – View and monitor heart rate information.
* 🌡️ **Temperature Monitoring** – Track body temperature readings.
* 📊 **Health Dashboard** – View important health information in one place.
* 📈 **Health History** – Store and view previous health records.
* 🚨 **SOS Emergency Alert** – Quickly access emergency assistance.
* 📍 **Live Location Support** – Provides location information during emergency situations.
* 📱 **User-Friendly Interface** – Simple and easy-to-use Flutter application.

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Shared Preferences** – For storing local health history.
* **FL Chart** – For displaying health data through charts.
* **Geolocator** – For location services.
* **URL Launcher** – For launching emergency calls and related actions.

## 🔄 How It Works

1. The user opens the **HealthGuard AI** application.
2. The home dashboard displays health information such as heart rate and temperature.
3. Health records can be stored and accessed through the **History** section.
4. The application visualizes health data using charts for easier understanding.
5. In an emergency, the user can use the **SOS Emergency** feature.
6. Location services can assist in sharing the user's current location during an emergency.

## 🎯 Project Objective

The main objective of HealthGuard AI is to provide a convenient digital solution for **basic health monitoring and emergency assistance**. The application aims to make important health information easily accessible while providing a quick way to initiate emergency actions.
